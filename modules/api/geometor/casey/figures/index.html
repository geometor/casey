geometor.casey.figures¶

Exact symbolic 5-layer .euclid-graphic SVG figure builders for Casey’s Sequel to Euclid.

Builds and exports all 21 interactive calibrated .g1.svg plates paired with the 1888 archival bitmap plates across Books I, II, III, IV, VI, and the Supplementary Chapter. Every point, line, circle, polygon, and intersection is constructed strictly over exact SymPy rationals / closed-form expressions (never float or sympy.Float) using Model(..., auto_intersect=False).
