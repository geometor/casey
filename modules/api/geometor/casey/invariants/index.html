geometor.casey.invariants¶

Exact symbolic circle, inversion, polar, and Euclidean helper invariants for Casey’s Sequel.

All algebraic predicates and compass-and-straightedge sub-constructions operate strictly over exact SymPy expressions (sympy.Rational, sympy.Integer, and closed-form radicals) without floating-point approximations.

geometor.casey.invariants.circle_power(pt: sympy.geometry.Point, circ: sympy.geometry.Circle) → sympy.Expr¶

Compute the exact power |PO|^2 - r^2 of point pt with respect to circ.

Corresponds to Casey, Book III, Props. 20–24 (pp. 41–44): for exterior points, equals the square of the tangent from pt to circ.

Parameters:

  • pt – Query point P.

  • circ – Reference circle (O, r).

Returns:

Exact symbolic expression (P.x - O.x)^2 + (P.y - O.y)^2 - r^2.

geometor.casey.invariants.are_orthogonal_circles(c1: sympy.geometry.Circle, c2: sympy.geometry.Circle) → bool¶

Return True iff circles c1 and c2 cut orthogonally (Casey Book III, Prop. 22).

Two circles cut orthogonally iff the square of the distance between their centres equals the sum of the squares of their radii: |O1 O2|^2 = r1^2 + r2^2.

Parameters:

  • c1 – First circle (O1, r1).

  • c2 – Second circle (O2, r2).

Returns:

True if |O1 O2|^2 - r1^2 - r2^2 == 0 symbolically.

geometor.casey.invariants.bitangent_quadrance(c1: sympy.geometry.Circle | sympy.geometry.Point, c2: sympy.geometry.Circle | sympy.geometry.Point, *, internal: bool = False) → sympy.Expr¶

Compute the exact squared common-tangent length t_12^2 between circles or null-circles.

In Casey’s Generalized Ptolemy Theorem (Book VI, Sec. IV, Prop. 10, pp. 103–104), a point is treated as a circle of radius 0. For two circles soaked in the same sense (external common tangent), t_12^2 = |O1 O2|^2 - (r1 - r2)^2; for transverse (internal) contact, t_12^2 = |O1 O2|^2 - (r1 + r2)^2.

Parameters:

  • c1 – First sympy.geometry.Circle or null-circle sympy.geometry.Point.

  • c2 – Second sympy.geometry.Circle or null-circle sympy.geometry.Point.

  • internal – If True, use (r1 + r2)^2 (internal bitangent); otherwise (r1 - r2)^2.

Returns:

Exact symbolic squared bitangent length.

geometor.casey.invariants.invert_point(pt: sympy.geometry.Point, center: sympy.geometry.Point, radius_sq: sympy.Expr) → sympy.geometry.Point¶

Compute the exact circular inverse of pt with respect to (center, sqrt(radius_sq)).

Implements Casey, Book III, Def. (p. 41) & Book VI, Sec. IV, Def. (p. 95): collinear with center and pt on the same ray such that |O P| * |O P'| = k^2.

Parameters:

  • pt – Point P distinct from center.

  • center – Centre of inversion O.

  • radius_sq – Square k^2 of the radius of inversion.

Returns:

Exact inverted sympy.geometry.Point P'.

Raises:

ValueError – If pt coincides with center.

geometor.casey.invariants.polar_line(pt: sympy.geometry.Point, circ: sympy.geometry.Circle) → sympy.geometry.Line¶

Compute the exact polar line of pt with respect to circ (Casey Book III, Def. p. 44).

By Casey’s definition, the polar of P with respect to (O, r) is the perpendicular to ray OP erected at the inverse point P' of P. Note that sympy.geometry.Circle natively lacks polar_line and pole_of_line methods.

Parameters:

  • pt – Pole P distinct from circ.center.

  • circ – Reference circle (O, r).

Returns:

Exact sympy.geometry.Line representing polar(P).

Raises:

ValueError – If pt coincides with circ.center.

geometor.casey.invariants.pole_of_line(line: sympy.geometry.Line, circ: sympy.geometry.Circle) → sympy.geometry.Point¶

Compute the exact pole of line with respect to circ (Casey Book III, Def. p. 44).

Constructed algebraically as the circular inverse of the orthogonal foot of circ.center upon line.

Parameters:

  • line – Non-diametral sympy.geometry.Line.

  • circ – Reference circle (O, r).

Returns:

Exact sympy.geometry.Point whose polar with respect to circ is line.

Raises:

ValueError – If line passes through circ.center (pole is at infinity).

geometor.casey.invariants.barycentric_point(a_pt: sympy.geometry.Point, b_pt: sympy.geometry.Point, c_pt: sympy.geometry.Point, w_a: sympy.Expr, w_b: sympy.Expr, w_c: sympy.Expr) → sympy.geometry.Point¶

Compute the exact homogeneous barycentric point (w_a : w_b : w_c) on ABC.

Implements Casey’s Centre of Mean Position (Book I, Props. 17–18, pp. 12–13) and symmedian/Brocard weights (Supplementary Chapter, Secs. I–II).

Parameters:

  • a_pt – First vertex A.

  • b_pt – Second vertex B.

  • c_pt – Third vertex C.

  • w_a – Weight attached to A.

  • w_b – Weight attached to B.

  • w_c – Weight attached to C.

Returns:

Exact sympy.geometry.Point (w_a*A + w_b*B + w_c*C) / (w_a + w_b + w_c).

Raises:

ValueError – If w_a + w_b + w_c == 0.

geometor.casey.invariants.compass_perpendicular_line(model: geometor.model.Model, line_p1: sympy.geometry.Point, line_p2: sympy.geometry.Point, through: sympy.geometry.Point, *, off_line_ref: sympy.geometry.Point | None = None, ID: str = '', classes: list[str] | None = None, guide: bool = False) → sympy.geometry.Line¶

Construct the perpendicular to line line_p1 line_p2 through through.

Uses rational circle reflection (Euclid I.12) when through lies off the line, and Thales’s semicircle construction (Euclid III.31) via off_line_ref (or equilateral fallback) when through lies on the line—preserving rational fields without extraneous nested radicals whenever off_line_ref is provided.

Parameters:

  • model – Target Model.

  • line_p1 – First point defining the base line.

  • line_p2 – Second point defining the base line.

  • through – Point through which the perpendicular is drawn.

  • off_line_ref – Optional known point not lying on line_p1 line_p2 for Thales III.31.

  • ID – Optional explicit line identifier.

  • classes – Optional semantic CSS classes.

  • guide – Whether the perpendicular line should remain a guide.

Returns:

Exact perpendicular sympy.geometry.Line passing through through.

Construct the line through through parallel to line_p1 line_p2 (Euclid I.31).

Constructs the fourth vertex Q = line_p2 + through - line_p1 of parallelogram line_p1 line_p2 Q through by bisecting diagonal line_p2 through at M and doubling line_p1 M via circle (M, line_p1).

Parameters:

  • model – Target Model.

  • line_p1 – First point on the reference line.

  • line_p2 – Second point on the reference line.

  • through – Exterior point through which the parallel is drawn.

  • ID – Optional explicit line identifier.

  • classes – Optional semantic CSS classes.

  • guide – Whether the parallel line should remain a guide.

Returns:

Exact parallel sympy.geometry.Line passing through through.
